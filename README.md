This repository contains a Lean formalisation of [Improved Lower Bounds for Strong _n_-Conjectures](https://dx.doi.org/10.1017/S1446788725000084) by Rupert Hölzl, Sören Kleine and Frank Stephan. The documentation may be viewed [here](https://parcly-taxel.github.io/Redhill/docs).

The name Redhill is a location and corresponding MRT station in Singapore.
